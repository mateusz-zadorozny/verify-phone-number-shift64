# N01 — The plugin will never confirm that a phone number belongs to the customer

- Date, owner: 2026-09-22, Mateusz Zadorożny (maintainer)
- Context and the options weighed: the plugin is named "Verify Phone Number", but what it does is check whether a number is a real, well-formed number for the given country. Confirming that the number belongs to the person entering it — an SMS or one-time code — is a different product with different costs (a gateway, per-message billing, a delivery failure path, personal-data handling). The question put to the maintainer was whether that is permanently out of scope or a later phase, because in the WordPress.org directory the name invites that expectation.
- Decision and why: permanently out of scope. quote: "na stałe - ma sprawdzać tylko poprawność" — permanently; it is to check correctness only.
- Consequences, and what would make us revisit it: a change adding SMS or one-time-code confirmation contradicts this entry and is a blocker in review until a superseding row approved by the owner replaces it. The naming ambiguity remains and may need addressing in the directory listing text rather than in code.
- Status: active
